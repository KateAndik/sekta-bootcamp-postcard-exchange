# Что нужно для настоящего запуска

## До передачи адресов

- Утвердить с юристом правила акции, отдельные согласия, срок хранения и реквизиты оператора.
- Выбрать сервер и базу данных с первичным хранением персональных данных граждан РФ на территории РФ.
- Подключить домен и HTTPS.
- Создать Telegram-бота через BotFather и сохранить токен только в секретах сервера.
- Сформировать и вручную проверить матрицу доступных почтовых направлений на дату жеребьёвки.

## Секреты

- `ADMIN_PASSWORD`: уникальный пароль не короче 12 символов.
- `DATA_ENCRYPTION_KEY`: 32 случайных байта в hex, то есть 64 символа.
- `TELEGRAM_BOT_TOKEN`: токен BotFather.
- `TELEGRAM_BOT_USERNAME`: имя бота без `@`.

Файл `.env` не отправляется в репозиторий. Адреса нельзя писать в логи, аналитику и Telegram-сообщения.

## Рекомендуемый production-контур

Один сервер в РФ запускает веб-приложение и бота. Для реального потока JSON-хранилище из MVP нужно заменить PostgreSQL с шифрованием чувствительных полей, резервным копированием и журналом административных действий. Админку лучше перевести с одного пароля на персональные учётные записи с двухфакторной авторизацией.

## Безопасная последовательность жеребьёвки

1. Бот проводит повторную перекличку.
2. Администратор проверяет неподтверждённых участников и матрицу стран.
3. Сервер строит распределение. Если корректного распределения нет, ничего не сохраняется.
4. Администратор подтверждает результат.
5. Бот отправляет каждому участнику одноразовую защищённую ссылку, но не сам адрес.
6. После завершения акции адреса удаляются по утверждённому регламенту.
