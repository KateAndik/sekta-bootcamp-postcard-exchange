# «Почта из лагеря» — рабочий MVP

В проекте есть публичная анкета, закрытая админка, зашифрованное хранилище, алгоритм жеребьёвки и Telegram-бот. Пока не утверждены юридические тексты и российский хостинг, вводить настоящие адреса нельзя.

При запуске через `server.mjs` закрытая часть `/admin` требует логин и пароль. Простое открытие `index.html` остаётся только визуальным preview и не обеспечивает серверную защиту.

## Локальный запуск

1. Скопировать `.env.example` в `.env`.
2. Задать длинный пароль администратора и случайный ключ из 64 шестнадцатеричных символов.
3. Запустить `npm start`.
4. Открыть `http://localhost:4173`; админка — `http://localhost:4173/admin`.
5. После создания Telegram-бота заполнить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_BOT_USERNAME`, затем отдельно запустить `npm run bot`.

## Запуск на сервере через Docker

На сервере достаточно установить Docker, создать `.env` по шаблону и выполнить `docker compose up -d --build`. PostgreSQL, сайт и бот запустятся как три связанных закрытых сервиса. Снаружи публикуется только сайт через HTTPS-прокси сервера #Sekta.

Для проверки алгоритма: `npm test`.

## Что можно проверить

- путь участника: адрес → география → отдельные согласия → сохранение заявки → подключение Telegram;
- выбор внутренней или международной отправки;
- ошибки незаполненной формы;
- отметку отправки открытки;
- закрытый вход команды и реальные счётчики заявок;
- жеребьёвку с учётом стран и доступных международных маршрутов;
- desktop и mobile layout.

## Что ещё нужно до запуска

- утверждённые юридические тексты и реквизиты оператора;
- сервер и резервное копирование на территории РФ;
- домен, HTTPS и production-секреты;
- актуальная ручная проверка почтовых маршрутов;
- уведомления после жеребьёвки и защищённая страница конкретного адресата;
- политика удаления и автоматическая очистка после акции;
- финальные юридические документы.

Перед боевым запуском использовать требования из `PROJECT-BRIEF.md`.
